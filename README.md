# 📌 Overview

Managing invoices manually is time-consuming, repetitive, and error-prone.  
**INVOXEN** is an AI-powered invoice analysis platform that simplifies invoice management using:

- OCR (Optical Character Recognition)
- AI-driven data extraction
- Smart categorization
- Financial analytics dashboard

Users can upload invoices in multiple formats, and the system automatically extracts important financial information such as:

- Merchant details
- Invoice date
- Total amount
- GST/Tax
- Purchased items

The platform further categorizes expenses and generates actionable insights through an interactive dashboard.

# 🚀 Key Features

## 📤 Invoice Upload

- Supports **PDF, JPG, and PNG**
- Handles both:
  - Digital invoices
  - Scanned invoices
- Drag & Drop Upload Interface
- Real-time preview before upload

---

## 🔍 Intelligent Data Extraction

Automatically extracts:

- Merchant Name
- Invoice Date
- Invoice ID
- Total Amount
- Tax / GST
- Currency
- Line Items

### OCR Technology Used

- Google Vision API
- Embedded PDF text extraction fallback
- Image OCR support using Tesseract.js

---

## 🧠 Smart Expense Categorization

Automatically classifies invoices into categories such as:

- 🍔 Food
- 🛒 Shopping
- ✈ Travel
- ⚡ Utilities
- 🎬 Entertainment
- 💻 Electronics

Uses:
- Rule-based categorization
- AI extensible architecture
